## A1 · 学籍管理规定（华师本〔2025〕78号，2025 年修订）

来源文件章节：`华东师范大学2025年本科生手册.md` §本科生学籍管理规定（行 932-1152）

### A1-1 · 学制与最长学习年限 🎯🎯🎯
- 规则：本科专业**标准学习年限（学制）为 4 年**，**最长学习年限（含休学和保留学籍）为 6 年**，自获得普通高等学校学籍起算。
- 原文：「学校全日制本科专业标准学习年限（学制）为4年，最长学习年限（含休学和保留学籍）为6年，自获得普通高等学校学籍起算。」
- 来源：§第三章 入学与注册 / 第十五条
- 落地：track_requirement(kind=`time_limit`, threshold=6, metadata={ unit:"year", direction:"upper", standard:4 })

### A1-2 · 新生入学逾期 → 放弃资格 🎯
- 规则：新生持录取通知书按规定期限到校；未请假/请假未获批准/请假期满**逾期 2 周**未到校注册的，视为放弃入学资格。
- 原文：「请假一般不得超过 2 周。除因不可抗力等正当事由外，未请假、请假未获批准或请假期满逾期2周未到校注册的，视为放弃入学资格。」
- 来源：§第三章 / 第八条
- 落地：track_requirement(kind=`time_limit`, threshold=2, metadata={ unit:"week", direction:"deadline", consequence:"forfeit_admission" })

### A1-3 · 保留入学资格 🎯
- 规则：新生可在报到日期前申请保留入学资格 →（1）应征参军至退役后 **2 年**；（2）其他情况保留 **1 年**；最迟保留期满前 1 周申请入学。
- 原文：「应征参加中国人民解放军（含中国人民武装警察部队），保留入学资格至退役后2年。」「其余情况保留入学资格期限为1年。」「学生最迟应在保留入学资格期满前 1 周，向学校申请入学。」
- 来源：§第三章 / 第十条 / 第十一条
- 落地：track_requirement(kind=`time_limit`, threshold=2, metadata={ unit:"year", scope:"admission_hold", branches:{ enlistment:2, other:1 } })

### A1-4 · 入学复查
- 规则：学生入学后，学校**在 3 个月内**按国家招生规定进行复查；复查不合格者可取消学籍。
- 原文：「学生入学后，学校在 3 个月内按照国家招生规定进行复查。复查不合格者，由学校根据情况予以处理，直至取消学籍。」
- 来源：§第三章 / 第十二条
- 落地：prompt（过程类）

### A1-5 · 学期注册（春秋两学期，缴费即注册）🎯
- 规则：春秋两学期学生须在学校规定时间内办理注册手续；因故不能如期注册的应申请暂缓注册，**暂缓期限一般不超过 2 周**；休学/保留学籍/未缴学费/其他不符合注册条件的不予注册。
- 原文：「春季与秋季学期，学生须在学校规定时间内办理注册手续。因故不能如期注册的，应在注册日期前向学校申请暂缓注册。暂缓期限一般不超过2周。」「休学、保留学籍、未按学校规定缴纳学费或其他不符合注册条件的，不予注册。」
- 来源：§第三章 / 第十三条 / 第十四条
- 落地：track_requirement(kind=`time_limit`, threshold=2, metadata={ unit:"week", scope:"registration_grace" })

### A1-6 · 选课前置（已注册才能选课）🎯
- 规则：**未注册者不予选课**；已注册的学生应按培养方案、在学部院系指导下自主修读课程；学生学业成绩由学校建立完善的考核体系评定，采用 GPA 作综合评价指标。
- 原文：「未注册者不予选课。已注册的学生应按照专业培养方案，在学部院系指导下，自主修读课程，参加养成教育活动。」
- 来源：§第四章 考核与成绩记载 / 第十六条
- 落地：track_requirement(kind=`status_gate`, threshold=null, metadata={ gate:"registered", required_for:"course_selection" })

### A1-7 · 转专业（除限制外均可申请）🎯
- 规则：学生在学期间对其他专业有兴趣或专长的，或基于课程修读情况，可按学校规定申请转专业。**以特殊招生形式录取的、国家有相关规定或者录取前与学校有明确约定的，不得转专业**（详见 C5 段）。
- 原文：「学生在学期间对其他专业有兴趣或专长的，或基于课程修读情况，可按照学校规定申请转专业。以特殊招生形式录取的、国家有相关规定或者录取前与学校有明确约定的，不得转专业。」
- 来源：§第五章 转专业与转学 / 第二十五条
- 落地：prompt（细则放 C5 重写）

### A1-8 · 转学限制情形 🎯
- 规则：以下情形**不得转学**：
  - (一) 入学未满一学期或者毕业前一年的；
  - (二) 高考成绩低于拟转入学校相关专业同一生源地相应年份录取成绩的；
  - (三) 由低学历层次转为高学历层次的；
  - (四) 以定向就业招生录取的；
  - (五) 无正当转学理由的。
- 原文：「学生一般应在本校完成学业，因患病或特殊困难、特别需要，无法继续在本校学习或者不适应本校学习要求的，可以申请转学。有下列情形之一，不得转学：...」
- 来源：§第五章 / 第二十六条
- 落地：prompt

### A1-9 · 休学规则（≤2 年 / 创业不计 / 应征不计）🎯🎯
- 规则：休学最小单位为 **1 学期**，**累计不超过 2 年**；
  - **休学创业**经审核通过，**休学年限不计入最长学习年限**，累计仍不超过 2 年；
  - **应征参军**保留学籍至退役后 2 年，**不计入最长学习年限**。
- 原文：「休学最小单位为1学期，累计不超过 2年。」「休学创业学生，经审核通过的，休学年限不计入最长学习年限，累计不超过2 年。」「在校生应征参加中国人民解放军（含中国人民武装警察部队），保留学籍至退役后2年。」
- 来源：§第六章 休学与复学 / 第二十九条—第三十一条
- 落地：track_requirement(kind=`time_limit`, threshold=2, metadata={ unit:"year", scope:"leave_total_cap", exemptions:["entrepreneur","enlistment"] })

### A1-10 · 退学情形（7 条触发）🎯🎯🎯
- 规则：学生有下列情形之一可予以退学：
  - (一) 学业成绩未达学校要求 ——「**除第一学年秋季学期外，单个长学期获得学分低于培养方案规定总学分的 10%，且累计获得学分低于总学分的 10% × 长学期数**」；
  - (二) 在学校规定的学习年限内未能毕业或结业的；
  - (三) 休学/保留学籍期满，规定期限内未提出复学申请或申请复学经复查不合格的；
  - (四) 经学校指定医院诊断，患有疾病或意外伤残无法继续在校学习的；
  - (五) 未经批准**连续两周未参加学校规定的教学活动**的；
  - (六) **超过学校规定期限未注册而又未履行暂缓注册手续**的；
  - (七) 学校规定的不能完成学业、应予退学的其他情形。
- 原文：「学业成绩未达到学校要求，即除第一学年秋季学期外，学生在单个长学期获得学分低于培养方案规定总学分的10%，且累计获得学分低于总学分的10%*长学期数的；...未经批准连续两周未参加学校规定的教学活动的；超过学校规定期限未注册而又未履行暂缓注册手续的...」
- 来源：§第七章 退学与试读 / 第三十四条
- 落地：track_requirement(kind=`warning_threshold`, threshold=10, metadata={ unit:"percent_of_total_credits", per_semester_min:10, cumulative_formula:"10% × N_semesters", consequence:"dropout", first_fall_excluded:true })

### A1-11 · 试读机制 🎯
- 规则：学生有第三十四条第（一）项情形（学业成绩未达学校要求）的，经学部院系审核同意，**可申请试读**。
- 原文：「学生有第三十四条第（一）项情形的，经学生所在学部院系审核同意，学生可根据学校规定申请试读。」
- 来源：§第七章 / 第三十五条
- 落地：prompt（细则在学业预警工作细则放 B 段重写）

### A1-12 · 毕业 / 结业 / 肄业三档（基础条款）🎯🎯
- 规则：
  - **毕业**：在规定学习年限内完成专业培养方案要求，成绩合格、获得相应学分并达到学校其他毕业要求 → 准予毕业，发毕业证书；符合学位授予条件的颁发学位证书。
  - **结业**：学习年限内未达毕业要求但所获学分达培养方案规定总学分 **90%** 及以上 → 准予结业，发结业证书。结业学生在最长学习年限内可申请返校补修完成毕业要求。
  - **肄业**：学满 1 年以上、所获学分达培养方案规定总学分 **10%** 的退学学生 → 可获肄业证书。
  - **写实性学习证明**：未达肄业证书条件的，可出具。
  - **取消学籍**：学校不出具肄业证书或写实性学习证明。
- 原文：「学生在学习年限内未达毕业要求但所获得学分达到专业培养方案规定总学分的90%及以上的，准予结业，发给结业证书。」「凡学满一年以上、所获学分达到专业培养方案规定总学分的10%的退学学生，可获得肄业证书。」
- 来源：§第八章 毕业与结业 / 第三十七条—第三十九条
- 落地：track_requirement(kind=`status_gate`, threshold=null, metadata={ tiers:[{ status:"毕业", pct:100 },{ status:"结业", pct:90 },{ status:"肄业", pct:10, duration_min:"1_year" },{ status:"写实证明", pct:"<10%" }], blocked_when:"revoked_enrollment" })

### A1-13 · 学历学位证书撤销（学术不端）🎯
- 规则：以作弊、剽窃、抄袭等学术不端行为或其他不正当手段获得学历证书/学位证书的，**依法予以撤销**；被撤销的证书已注册的，学校予以注销并报教育行政部门宣布无效。辅修专业相关证书参照执行。
- 原文：「对以作弊、剽窃、抄袭等学术不端行为或者其他不正当手段获得学历证书、学位证书的，依法予以撤销。」
- 来源：§第八章 / 第四十二条
- 落地：track_requirement(kind=`status_gate`, threshold=null, metadata={ gate:"academic_integrity", consequence:"revoke_certificate" })

## A2 · 毕业资格审核工作细则（华师本〔2025〕71号）

来源文件章节：`华东师范大学2025年本科生手册.md` §本科生毕业资格审核工作细则（行 1818-1850）

### A2-1 · 三档结果（毕业 / 结业 / 退学 / 肄业 / 写实证明）🎯🎯🎯
- 规则：毕业、结业以审核毕业资格时学生所绑定的**专业培养方案要求为准**：
  - **毕业**：学习年限内完成专业培养方案规定**全部课程**，成绩合格，获得相应学分并达到学校规定的毕业要求；
  - **结业**：未达毕业要求，但所获学分达培养方案规定总学分的 **90% 及以上**；
  - **退学**（未达结业要求）→ 学满 1 年以上、所获学分达总学分 **10%** 的发**肄业证书**；未达肄业要求的出具写实性学习证明。
- 原文：「（一）学生在学校规定的学习年限内完成专业培养方案规定全部课程，成绩合格，获得相应学分并达到学校规定的毕业要求...（二）...所获得学分达到专业培养方案规定总学分的90%及以上的，达到结业要求...（三）...所获学分达到专业培养方案规定总学分10%的，发给肄业证书；未达到肄业要求的，出具写实性学习证明。」
- 来源：§第四条 (一)(二)(三)
- 落地：track_requirement(kind=`status_gate`, threshold=null, metadata={ tiers:[{ status:"毕业", criterion:"all_courses_done + credits_met" },{ status:"结业", credit_pct:90 },{ status:"肄业", credit_pct:10, duration_min:"1_year" },{ status:"写实证明", criterion:"otherwise" }] })

### A2-2 · 提前毕业 🎯🎯
- 规则：预计早于标准学习年限完成培养方案的，**一般应在本校修读满 3 年**；学生应**提前 1 个学期**向所在学部院系提出申请，经审核报本科生院备案。后因故无法按期可在毕业资格审核前申请撤销提前毕业。
- 原文：「预计早于标准学习年限完成培养方案规定毕业条件的，学生可申请提前毕业。一般应在本校修读满3年。」「学生应提前 1 个学期，向所在学部院系提出提前毕业申请，经所在学部院系审核培养方案完成情况后，报本科生院备案。」
- 来源：§第五条
- 落地：track_requirement(kind=`time_limit`, threshold=3, metadata={ unit:"year", direction:"lower", scope:"early_graduation_min_residency", apply_advance:"1_semester" })

### A2-3 · 延期毕业 🎯
- 规则：预计在标准学习年限内无法达到毕业或学位申请条件的，**可在学校规定时限内申请延长学习年限**。**未提出延期申请的根据学业完成情况进行毕业资格审核**。
  - 延期毕业的学生应正常到校报到注册；**无正当理由逾期 2 周未办理注册手续的**，根据学业完成情况进行毕业资格审核；
  - **延期内未选课的学期，学生应办理休学**。
- 原文：「预计在标准学习年限内无法达到毕业或学位申请条件的，学生可在学校规定时限内，申请延长学习年限。」「延期毕业的学生应正常到校报到注册。无正当理由逾期 2 周未办理注册手续的，根据学业完成情况进行毕业资格审核。延期内未选课的学期，学生应办理休学。」
- 来源：§第六条 / 第七条
- 落地：prompt（流程类，触发条件落 track_requirement 不经济）

### A2-4 · 结业生返校补修 🎯
- 规则：在最长学习年限内，**结业学生可申请返校补修课程或完成毕业要求**；通过申请的，返校学习后达到毕业条件的，**准予毕业并换发毕业证书，毕业时间以换发证书日期为准**；达到学士学位申请条件的可申请学士学位。
- 原文：「在最长学习年限内，结业学生可申请返校补修课程或完成毕业要求。通过申请的，返校学习后，达到毕业条件的，准予毕业并换发毕业证书,毕业时间以换发证书日期为准。」
- 来源：§第九条
- 落地：prompt（与 A1-12 结业档对应的工作流）

### A2-5 · 审核责任
- 规则：**学生所在学部院系负责毕业资格初审**；**本科生院负责毕业资格复审**。
- 原文：「学生所在学部院系负责毕业资格初审。本科生院负责毕业资格复审工作。」
- 来源：§第三条
- 落地：prompt

## A3 · 全日制本科学士学位授予工作细则（华师本〔2025〕48号，2025 年修订）

来源文件章节：`华东师范大学2025年本科生手册.md` §华东师范大学全日制本科学士学位授予工作细则（行 1856-1908）

### A3-1 · 学位申请基本条件
- 规则：在学校接受本科教育，**通过规定的课程考核或者修满相应学分，通过毕业论文或者毕业设计等毕业环节审查，达到《中华人民共和国学位法》规定的学士学位申请人基本条件**，且学业要求满足 A3-2 条件之一的，可申请学士学位。
- 原文：「在学校接受本科教育，通过规定的课程考核或者修满相应学分，通过毕业论文或者毕业设计等毕业环节审查，达到《中华人民共和国学位法》规定的学士学位申请人基本条件...」
- 来源：§第四条
- 落地：track_requirement(kind=`status_gate`, threshold=null, metadata={ gate:"degree_prereq", checks:["course_exam_passed","thesis_passed","law_basic"] })

### A3-2 · GPA 阈值 🎯🎯🎯
- 规则：申请学士学位需 GPA 满足下列条件之一：
  - **全日制本科毕业生 GPA ≥ 2.0**；
  - **特定地区班和预科特定学生群体毕业生 GPA ≥ 1.8**；
  - 来华留学本科毕业生应达到毕业条件即可。
- 原文：「(一)全日制本科毕业生平均学分绩点应达到2.0；( 二 ) 特定地区班和预科特定学生群体毕业生平均学分绩点应达到 1.8；(三)来华留学本科毕业生应达到毕业条件。」
- 来源：§第四条 (一)(二)(三)

### A3-3 · 处分期间不可申请 🎯

## A4 · 本科生成绩及学分认定工作细则（华师本〔2025〕76号）

来源文件章节：`华东师范大学2025年本科生手册.md` §华东师范大学本科生成绩及学分认定工作细则（行 1660-1734）

### A4-1 · 适用情形
- 规则：申请认定的成绩及学分适用以下情形：
  - (一) 已修读的本校**跨专业课程**（含转专业）；
  - (二) 已修读的本校**研究生课程**；
  - (三) 已完成的**经学校审批备案的跨校学习项目**；
  - (四) 本校**插班生、转学生已修读的外校课程**；
  - (五) **在两年内重新参加入学考试被本校录取前已修读的课程**；
  - (六) 其他须经学校认定成绩及学分的情况。
- 原文：「(一)已修读的本校跨专业课程（含转专业）...(五)在两年内重新参加入学考试被本校录取前已修读的课程...」
- 来源：§第二条
- 落地：prompt（流程类）

### A4-2 · 认定上限 🎯🎯🎯
- 规则：申请认定的成绩及学分应满足下列条件：
  - (一) **已获得学分**方可用于申请认定；
  - (二) **累计认定学分数一般不超过在读培养方案总学分的 40%**；
  - (三) 学生赴外校交流学习的选课方案或学习计划应**提前**经所在学部院系审核通过。
- 原文：「(二)累计认定学分数一般不超过在读培养方案总学分的40%；」
- 来源：§第三条
- 落地：track_requirement(kind=`gpa_threshold`, threshold=40, metadata={ unit:"percent_of_total_credits", scope:"credit_recognition_cap", direction:"upper" })

### A4-3 · 认定原则 🎯
- 规则：成绩及学分认定遵循：
  - (一) **同一次学习经历仅受理 1 次**成绩及学分认定申请；
  - (二) **更高教学要求、内容和学时数的课程或项目可替代较低要求的同类课程或项目**；外校课程的教学要求、教学内容和学时数应达到并符合本校培养方案对应课程的要求；
  - (三) 学分认定可按课程与课程、课程与课程组的对应关系，**被认定学分总数不超过实际修读学分总数**；
  - (四) **已获得学分的本校课程原则上不可被替代**；
  - (五) 学分核算基准一般按本校学分与学时对应关系，外校学分体系与本校不一致的，以该校正式发布或出具的学分体系说明为依据；
  - (六) **境外高校所获学分不可认定为思想政治理论课程学分**；
  - (七) 成绩及学分认定完成后不再修改。
- 原文：「(六)境外高校所获学分不可认定为思想政治理论课程学分；（七）成绩及学分认定完成后不再修改。」
- 来源：§第四条
- 落地：track_requirement(kind=`assessment_rule`, threshold=null, metadata={ scope:"credit_recognition_rules", once_per_experience:true, higher_replaces_lower:true, no_replace_existing:true, overseas_excluded_categories:["political_theory"] })

### A4-4 · 申请流程
- 规则：流程：学生在规定受理时间向所在学部院系提交认定申请（附**官方成绩单、成绩说明、课程教学大纲**） → 学部院系会同开课单位审核 → 本科生院复核。**外校项目认定应在项目结束返校的首个学期提出申请**；未在规定期限内提交认定申请的视作放弃。
- 原文：「外校项目认定应在项目结束返校的首个学期提出申请，未在规定期限内提交认定申请的，视作放弃认定。」
- 来源：§第五条
- 落地：prompt

### A4-5 · 记载方式 🎯
- 规则：经认定后的成绩和学分记载方式：
  - (一) **外校修读课程予以标注 "*"**；
  - (二) **多门课程认定为一门课程的，课程总评记为 P**；
  - (三) 经认定为**公共课程和通识教育模块课程的，记录成绩和学分，不记课程绩点**；
  - (四) 经认定为**学科基础课程和专业教育课程的，记录成绩和学分。课程绩点的计分方式由学生所在学部院系决定**。
- 原文：「（一）外校修读课程予以标注 "" 。（二）如多门课程认定为一门课程的，课程总评记为P。( 三 ) 经认定为公共课程和通识教育模块课程的，记录成绩和学分，不记课程绩点。」
- 来源：§第七条
- 落地：track_requirement(kind=`score_scheme`, threshold=null, metadata={ scope:"credit_recognition_grading", external_mark:"*", multi_to_one_grade:"P", general_no_gpa:true, professional_gpa_by_dept:true })

## A5 · 本科生课程考核管理办法（华师本〔2025〕79号）

来源文件章节：`华东师范大学2025年本科生手册.md` §本科生课程考核管理办法（行 1410-1500）

### A5-1 · 考核形式与时间
- 规则：
  - 课程考核分**考试课程和考查课程**两种；
  - 考核形式包括**笔试、口试、实践操作（实验、实践、训练）、撰写论文（作品、课程报告）**等；
  - 考核时间为**期末考核和随堂考核**；
  - **期末考试周专业课每天考核科目一般不得多于 2 门**；
  - 考查课程、暑期学期课程一般安排随堂考核。
- 原文：「专业教育课程考核的时间由开课单位统一安排。安排在期末考试周的，各专业各年级每天考核科目一般不得多于2门。」
- 来源：§第三章 / 第七条—第九条
- 落地：prompt（学校组织层面）

### A5-2 · 考核资格（缺课/缺交 > 1/3 取消）🎯🎯
- 规则：**学生缺课学时或缺交作业次数累计超过教学规定要求三分之一（1/3）**的，**取消该课程考核资格**。确有特殊情况的，由学生所在院系与开课单位协商一致后确认是否给予考核资格或缓考资格，报本科生院备案。
- 原文：「学生应按规定参加课程考核。缺课学时或缺交作业次数累计超过教学规定要求三分之一的，取消该课程考核资格。」
- 来源：§第四章 / 第十一条
- 落地：track_requirement(kind=`assessment_rule`, threshold=null, metadata={ scope:"exam_eligibility", check:"absence_or_missed_assignment", max_fraction:"1/3", consequence:"disqualify" })

### A5-3 · 缓考申请（开考前 2 天）🎯
- 规则：因考核冲突、患病或其他情况不能按时参加的，**最迟应在开考前 2 天**向所在院系申请缓考。**突发疾病或事故的应在事发后的 2 个工作日内**向所在院系补交申请并提供证明材料（突发疾病需二级甲等以上医院病历或病假单）。**未办理缓考申请或申请未批准的视为缺考**。
- 原文：「因考核冲突、患病或其他情况，不能按时参加的，最迟应在开考前2天向所在院系申请缓考。」「突发疾病或事故的，应在事发后的2个工作日内向所在院系补交申请，并提供证明材料。」
- 来源：§第四章 / 第十二条
- 落地：track_requirement(kind=`time_limit`, threshold=2, metadata={ unit:"day", scope:"defer_exam_apply", direction:"before_exam", emergency_window:"2_workdays_after" })

### A5-4 · 不予补考情形 🎯🎯
- 规则：课程考核**不合格**的学生**可申请补考或重修**。但以下情况**不予补考**：
  - (1) 缺考；
  - (2) 考核违纪；
  - (3) 取消考核资格；
  - (4) 缓考不合格。
- 原文：「课程考核不合格的，学生可申请补考或重修。缺考、考核违纪、取消考核资格、缓考不合格等情况，不予补考。」

### A5-5 · 补考课程范围 🎯
- 规则：补考、缓考**限必修课程和专业选修课程**；**公共体育课程、通识教育课程、实践实习类课程及考查类型课程不设补考**；**暑期学期课程不设缓考和补考**。
- 原文：「补考、缓考限必修课程和专业选修课程，具体课程由开课单位确定。公共体育课程、通识教育课程、实践实习类课程及考查类型课程不设补考。暑期学期课程不设缓考和补考。」

- 规则：**补考时间由开课单位安排**：
  - 秋季学期课程的补考一般安排在**春季学期第一周**；
  - 春季学期课程的补考一般安排在**暑期学期最后一周或秋季学期开学前一周**；

- 原文：「秋季学期课程的补考一般安排在春季学期第一周，春季学期课程的补考一般安排在暑期学期最后一周或秋季学期开学前一周。缓考时间同补考时间。」

## 设计决策（v2 全 digest 复用）

> 试点 A 阶段拍板，后续 B / C / D / E 沿用，不再逐份重审。

1. **多条款合一条**（A1-3 / A1-9 / A4-3 / A5-4 / A5-5 类）：同一法律条文下的子项归并为一条 digest 行，靠 `metadata.branches` / `metadata.blocked_states` / `metadata.excluded_categories` 数组表达分支。**不拆**。理由：拆开会让 INSERT 数 +50% 但语义不增；UI 按 `metadata.scope` 路由模板更清。
2. **跨 digest 重叠规则**（A1-7/8 ↔ C5 段；A1-11 ↔ B 学业预警；A3-5/6 ↔ C1/C2）：先出现的 digest 留**指引行 + prompt**，落地细则放主负责 digest（升级 track_requirement）。digest 间 cross-link，避免重复 INSERT。
3. **`time_limit` 用 `metadata.direction` 表达上下限**：`upper`（最长 6 年学制）/`lower`（提前毕业 ≥ 3 年）/`deadline`（入学逾期 2 周）。**不新增 `min_duration` kind**，控制 12 档总数。
4. **GPA 阈值分支用 object 结构**（A3-2 模板）：每个分支是 `{ gpa_min: number|null, criterion?: string }`，下游 zod schema 单一签名兼容"无 GPA 阈值仅检查毕业条件"分支。
5. **AI 顾问无关条款删，不入 process_rules**：监考标准、考场座次、教师工作量等"学校内部组织层"规则在 digest 阶段直接删，不进阶段 4 `ecnu_process_rules.md`。process_rules 只放"跟学生有直接交互"的过程规则（如选课退课流程、转专业流程、休学复学手续等）。
6. **`source_ref` 格式统一**：`华东师范大学2025年本科生手册.md §{篇名} 第x条`（或 `§{篇名} 第x章 / 第y条` 用于教育部规定）。0005 seed SQL 的 INSERT 直接引这串。

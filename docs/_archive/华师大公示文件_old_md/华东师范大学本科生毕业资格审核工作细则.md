# 华东师范大学本科生毕业资格审核工作细则

华东师范大学文件
华师本〔2025〕71号
各单位：
为进一步规范全日制本科生毕业资格审核工作，制定《华东
师范大学本科生毕业资格审核工作细则》。现予印发，请遵照执行。
特此通知。
华东师范大学
2025年5月7日
第一条为进一步规范全日制本科生毕业资格审核工作，根
据《华东师范大学本科生学籍管理规定（2025年修订）》等有关
规定，结合实际，制定本细则。
第二条本细则适用于按照国家招生政策和规定录取，在学
校规定最长学习年限内的全日制本科生。
第三条学生所在学部院系负责毕业资格初审。本科生院负
责毕业资格复审工作。
第四条毕业、结业以审核毕业资格时学生所绑定的专业培
养方案要求为准。
（一）学生在学校规定的学习年限内完成专业培养方案规定
全部课程，成绩合格，获得相应学分并达到学校规定的毕业要求，
达到毕业条件，准予毕业并发给毕业证书。
（二）学生未达到毕业要求，但所获得学分达到专业培养方
案规定总学分的90%及以上的，达到结业要求，准予结业并发给
结业证书。
（三）学生未达到结业要求的，予以退学。学满一年以上、
所获学分达到专业培养方案规定总学分10%的，发给肄业证书；
未达到肄业要求的，出具写实性学习证明。
第五条预计早于标准学习年限完成培养方案规定毕业条件
的，学生可申请提前毕业。一般应在本校修读满3年。
学生应提前1个学期，向所在学部院系提出提前毕业申请，
经所在学部院系审核培养方案完成情况后，报本科生院备案。后
因故无法按期毕业的，可在毕业资格审核前向所在学部院系申请
撤销提前毕业，由学部院系报本科生院备案。
第六条预计在标准学习年限内无法达到毕业或学位申请条
件的，学生可在学校规定时限内，申请延长学习年限。未提出延
期申请的，根据学业完成情况进行毕业资格审核。
第七条延期毕业的学生应正常到校报到注册。无正当理由
逾期2周未办理注册手续的，根据学业完成情况进行毕业资格审
核。延期内未选课的学期，学生应办理休学。
第八条学生延期已达最长学习年限，根据学业完成情况进
行毕业资格审核。
第九条在最长学习年限内，结业学生可申请返校补修课程
或完成毕业要求。通过申请的，返校学习后，达到毕业条件的，
准予毕业并换发毕业证书，毕业时间以换发证书日期为准。达到
学士学位申请条件的，可申请学士学位。
第十条本细则由本科生院负责解释。
第十一条本细则自2025年9月1日起施行。原《华东师范
大学本科生毕业资格审核办法（2017年修订）》（华师教〔2017〕
132号）与《华东师范大学本科生提前毕业及延长修业期管理细
则》（华师教〔2021〕131号）同时废止。
华东师范大学学校办公室2025年5月16日印发

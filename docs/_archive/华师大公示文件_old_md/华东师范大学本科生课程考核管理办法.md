# 华东师范大学本科生课程考核管理办法

华东师范大学文件
华师本〔2025〕79号
各单位：
为加强本科教学过程管理，建立完善以学生培养质量为核心
的考核体系，制定《华东师范大学本科生课程考核管理办法》。现
予印发，请遵照执行。
特此通知。
华东师范大学
2025年5月7日
第一章总则
第一条为进一步升级以“学生自由而全面发展”为目标、
以“思维能力提升”为牵引的卓越育人模式，加强本科教学过程
管理，建立完善以学生培养质量为核心的考核体系，根据《华东
师范大学本科生学籍管理规定（2025年修订）》，结合实际，制定
本办法。
第二条本办法所称课程是指学校全日制本科培养方案中的
所有课程和教育教学环节。
第三条学校建立荣誉课程制度，鼓励学生修读具备高阶性、
创新性和挑战度的课程。
第四条课程考核是学业评价的重要手段。课程考核应以激
发学生学习动力和专业志趣为着力点，坚持学术道德与品格塑造
相结合、知识考核与能力考核相结合、过程性与结果性考核相结
合。鼓励以人工智能赋能，推动能力考核为导向的课程考核评价
方式改革，探索学业评价和考核模式多元化、微扰化、无形化。
第二章职责分工
第五条学校分管本科教学领导负责组织领导学校本科课程
考核管理工作。本科生院负责统筹安排全校本科生课程考核工作，
负责试卷质量监控、协调考核安排、巡考安排、处理学生考核违
纪等。
第六条各学部院系、公共教学单位负责课程考核组织工作，
落实考核安排、命题管理、考务培训、监考巡考、严肃考风考纪
等工作。院系分管教学领导负责本单位课程考核的组织管理。任
课教师须根据课程教学大纲要求，秉持客观公正原则评价学生修
读情况。教职工根据工作需要和岗位职责负责实施具体考务工作。
第三章考核安排
第七条根据课程考核方式分为考试课程和考查课程。考核
方式由任课教师或开课单位根据课程特点和教学要求确定。教学
大纲中须明确考核方式，任课教师应在第一次上课时予以明确。
第八条课程考核形式包括笔试、口试、实践操作（实验、
实践、训练）、撰写论文（作品、课程报告）等。
第九条课程考核时间为期末考核和随堂考核，选课时应予
以注明。
（1）公共课程考核的时间由本科生院和开课单位安排。
（2）专业教育课程考核的时间由开课单位统一安排。安排在
期末考试周的，各专业各年级每天考核科目一般不得多于2门。
（3）考查课程、暑期学期课程一般安排随堂考核。考核形式
为提交论文（作品、课程报告）的，任课教师应提前明确提交方
式及截止时间。
第十条课程考核安排一经发布，开课单位和任课教师均不
得随意改变。
第四章补考缓考与重修
第十一条学生应按规定参加课程考核。缺课学时或缺交作
业次数累计超过教学规定要求三分之一的，取消该课程考核资格。
确有特殊情况的，由学生所在院系与开课单位协商一致后，确认
是否给予课程考核资格或缓考资格，报本科生院备案。
第十二条因考核冲突、患病或其他情况，不能按时参加的，
最迟应在开考前2天向所在院系申请缓考。经所在院系批准同意
后，可予以缓考。突发疾病或事故的，应在事发后的2个工作日
内向所在院系补交申请，并提供证明材料。突发疾病的，需提交
二级甲等以上医院开具病历或病假单，病假单期间所有考核均按
缓考处理。未按要求办理缓考申请手续或缓考申请未批准的，视
为缺考。
第十三条课程考核不合格的，学生可申请补考或重修。缺
考、考核违纪、取消考核资格、缓考不合格等情况，不予补考。
第十四条补考、缓考限必修课程和专业选修课程，具体课
程由开课单位确定。公共体育课程、通识教育课程、实践实习类
课程及考查类型课程不设补考。暑期学期课程不设缓考和补考。
第十五条补考时间由开课单位安排。秋季学期课程的补考
一般安排在春季学期第一周，春季学期课程的补考一般安排在暑
期学期最后一周或秋季学期开学前一周。缓考时间同补考时间。
第五章命题与试卷
第十六条课程考核命题应以教学大纲的目标和要求为依
据，支撑覆盖课程教学目标，有一定的广度、难度和区分度，引
导学生深度思考，探索考核模式多元化、微扰化、无形化。
第十七条课程考核命题可由任课教师命题或实行教考分
离。鼓励公共必修课建立试题库，从试题库随机抽取试题。
第十八条同一门课程设平行教学班且教学要求一致的，一
般应统一评价标准、统一命题阅卷。
第十九条考核试卷属保密材料。按照“谁主管谁负责”原
则，开课单位分管教学领导应认真督促做好试卷的保密工作和保
存工作，对试卷的命题、印制、分送、保管等各环节承担保密管
理责任。
第二十条考核结束后，任课教师应分析考核结果，总结课
程教学活动中的经验和问题，提出课程教学和评价的改进思路和
方向。
第六章监考与巡考
第二十一条考场一般使用标准化考场，座次按教务系统考
场座位表或按隔位原则安排。考生人数少于90人的考场，一般安
排2人监考；考生等于或多于90人的考场，须安排3人以上监考。
第二十二条监考人员包括主考和监考。主考由任课教师担
任。公共教育课程监考由本科生院和开课单位安排，专业教育课
程监考由开课单位安排。学校专任教师应承担监考工作。监考人
员确有不足的，可适量安排当前学期的研究生助教，经考务培训
后承担监考工作。
第二十三条监考人员确因特殊情况无法承担已安排的监考
工作的，经开课单位审核同意后，由开课单位协调安排其他监考
人员并报备本科生院，不得擅自安排他人代替。如有亲属参加本
场考试的，监考人员应主动申请回避。
第二十四条监考人员必须认真履行监考职责，参加考务培
训，提前做好考务准备。监考期间不得从事无关工作，不得擅自
离开考场。
第二十五条本科生院负责安排学校领导、学校教学委员会委
员、校级教学督导和本科生院人员的考试周巡考。院系负责安排院
系领导、院系教学委员会成员、院系教学督导的巡考。巡考后须填
写《考场巡考记录单》，《考场巡考记录单》由巡考单位留存。
第七章考核纪律
第二十六条学生应自觉遵守考核纪律，有考核违纪的，按
《华东师范大学学生违纪处分办法》等规定给予相应处分。
第二十七条学生考核违纪行为的核实由开课单位负责。
考核过程中有违纪的，由监考负责停止该生考核、保留证
据、填写考核违纪单、证据材料报开课单位。开课单位须在发
现违纪的2个工作日内向本科生院报告，并将违纪材料反馈学
生所在院系。
非考核过程中发现违纪、学术不端或收到相关情况反映的，
应保留证据和记录，在发现违纪、学术不端的2个工作日内向本
科生院报告，由开课单位会同学生所在院系做好核实工作。
第二十八条对违纪情况逾期不报或隐瞒不报的单位和人
员，应予以通报，同时根据情况追究相关人员的责任。
第二十九条任课教师、监考和其他人员因直接或间接责任，
影响考核秩序、考核进程或成效的，按照《华东师范大学教学事
故认定与处理办法》等规定进行调查处理。
第八章附则
第三十条本办法由本科生院负责解释。
第三十一条本办法自2025年9月1日起施行，适用于全日
制本科生。原《华东师范大学本科生考试管理办法（2017年修订）》
（华师教〔2017〕137号）同时废止。

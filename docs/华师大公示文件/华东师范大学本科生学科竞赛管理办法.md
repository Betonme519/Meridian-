华东师范大学本科生学科竞赛管理办法
第一章总则
第一条学科竞赛是高校人才培养和深化创新创业教育改革
的重要环节，对培养学生创新思维和团队合作精神，提高创新实
践能力，促进学生全面发展起着重要作用。为发挥院系参与学科
竞赛的主体作用，激励师生积极参与高质量学科竞赛活动，促进
学科竞赛管理工作的规范化、科学化，特制定本办法。
第二章竞赛分类
第二条学校对学科竞赛进行分级分类管理。学科竞赛根据
主办单位和规模层次可分为国际级、国家级、省部级三个级别。
国际级学科竞赛（含分区赛），是指联合国教科文组织或其他
国际学术团体，或某国学术团体面向全球组织且参赛国来自三大
洲及以上的学科竞赛。
国家级学科竞赛是指国家政府部门、教学指导委员会或全国
性学术团体、行业学会（协会）组织的全国范围的学科竞赛。
省部级学科竞赛是指省（市）政府有关部门或省（市）级学
术团体等机构组织的全省（市）或跨省（市）区的学科竞赛，以
及全国性学科竞赛在全国各大赛区的选拔比赛。
第三条学科竞赛按学术水平和影响力分为高水平（A）和普
通（B）两类，全国普通高校学科竞赛排行榜收录的竞赛自动纳入
学校A类竞赛。由教务处组织竞赛的分类认定工作，每两年认定
一次，原则上于年初发布。
学校鼓励学生积极参加赛事规模大、学术水平高、组织规范、
奖项评比严格、在国内外享有声誉、能够提升参赛学生学术水平
和实践创新能力的学科竞赛，并提供经费和政策支持。
第三章组织与管理
第四条本科生学科竞赛工作由分管本科教学工作的校级领
导总领，教务处负责整体部署、统筹协调，相关学部（学院）负
责竞赛具体组织工作。
第五条教务处是本科生学科竞赛的管理机构，负责学科竞
赛的分类认定、预算与核拨竞赛经费、制定并实施奖励政策；组
织制定校级竞赛章程及实施方案；组织落实省部级以上竞赛的承
办工作；协调与监督各级各类学科竞赛，为本科生参加学科竞赛
提供基础保障；汇总全校竞赛获奖数据；成立竞赛研究团队进行
专门教学研究、推进教学改革。
第六条学科竞赛一般由学科所在学部（院系）负责牵头实
施，负责赛事的动员、报名、选拔、培训、参赛及总结工作，教
学副院长（副主任）负责落实竞赛实施工作，要在全校范围内组
织相关学科的学生报名参加，安排竞赛指导教师加强指导，配备
辅助人员，提供必要的场地及仪器设备，组织竞赛专家开展竞赛
命题和评审，做好比赛颁奖及赛事总结等工作。
第七条各学部（院系）应明确竞赛负责人并保持相对固定，
主要职责包括：了解各类竞赛章程、规范、报名要求等，认真制
定参赛方案；组织相关指导教师认真研究竞赛内容，制定并落实
参赛方案和培训计划；做好赛事宣传动员工作，提前选拔参赛学
生，做好各环节的指导、管理和服务；赛事结束后，及时总结参
赛情况并发布新闻稿；整理并在公共数据库中上报竞赛获奖数据、
分配学生奖励；配合做好创新创业学分认定。
第八条学校鼓励各学部（院系）成立学科竞赛研究团队，
开展本科生学科竞赛教学改革研究，优化参赛方案，拓展办赛思
路，总结参赛经验，提升学校本科生参赛办赛水平。
第四章经费支持
第九条教务处为A类竞赛指定牵头学部（院系），并提供专
项经费支持。牵头学部（院系）应在每年10月提交下一年度《华
东师范大学本科生学科竞赛年度工作方案》（附件一）并做好预算，
预算要本着节约高效的原则，各项支出详细具体并列明测算依据。
鼓励院系多渠道筹措竞赛经费。
第十条由教务处组织专家评审学科竞赛方案，根据赛事等
级、参赛情况给予相应资助，于次年年初统一划拨至牵头院系，
一般由竞赛负责人负责使用。
第十一条学科竞赛经费使用范围主要包括：比赛注册报名
费、参会费、差旅费；制作作品所需的印刷费、耗材费、设备费；
参加竞赛购买的培训书籍费；经教务处认可的多专业本科生参加
的竞赛所涉及出题费、监考费、阅卷费；其他与竞赛密切相关的
费用。获奖学生奖金、奖品不予支持。经费使用需符合学校财务
管理规定。
第十二条学校鼓励各学部（院系）承办有助于提高本校声誉、
能大幅提高学生学术水平和视野的学科竞赛，并提供经费资助。
第五章奖惩机制
第十三条竞赛获奖学生可根据学校创新创业学分认定办法
申请并获得相应学分；可根据学校推荐免试研究生有关规定获得
相应推免加分；教务处根据竞赛级别、获奖等第，对获奖学生予
以奖励，奖励标准参照相关规定执行。
第十四条学校鼓励教师积极承担赛事的培训指导工作，将
指导竞赛获奖纳入本科人才培养绩效奖励指标，各学部（院系）
应在绩效中考虑教师在学科竞赛指导与培训方面的工作量。
对于教务处认可的多个学部（院系）本科生参加且外专业占
一定比例的A类竞赛，学校鼓励牵头院系组织面向多数参赛学生
的统一培训指导，根据教师在该赛事备赛期间实际承担的培训量
和成效奖励相应的工作量。由牵头院系的竞赛负责人统一记录教
师在竞赛期间的工作量并折算为课堂教学时数，在赛事结束后填
写《华东师范大学本科生学科竞赛培训工作量申报单》（附件二）
《华东师范大学本科生学科竞赛教师工作量核定表》（附件三），
经牵头单位审核同意报送教务处，教务处核定后按当年本科教学
课时费标准计入教师所在单位的本科教学开课量绩效奖励。
第十五条在教师申请晋升职称时，学校为指导A类竞赛获奖
的教师奖励相应学时数并计入总教学工作量，即“年均全日制本
科生及研究生教学工作总量”，但不能抵充学校要求的主讲本科生
课程教学量部分。
教师指导学科竞赛奖励学时包含基本工作量、带队参赛工作
量和指导获奖工作量。基本工作量为5学时，项目数不重复计算，
工作任务包括研究比赛内容、指导学生训练和比赛等。带队参加
比赛，本市内按“2学时*竞赛天数”计算工作量，本市外按“3
学时*竞赛天数”计算工作量，总天数超过3天按3天计算。指导
获奖奖励标准如下：

第十六条学生参加各类竞赛，须遵守相关章程、严守学术
诚信。学校将依照《华东师范大学学生违纪处分办法》等相关规
定，对实施违反学术道德等行为的相关学生给予相应处分，对其
指导教师依照《华东师范大学教学事故认定与处理办法》给予相
应处分。
第六章附则
第十七条本办法自颁布之日起实行，具体条款由教务处负
责解释。

# 华东师范大学强基计划学生培养管理办法

华师本〔2025〕7号
各单位：
学校对《华东师范大学强基计划学生培养管理办法（试行）》
（华师教〔2020〕112号）进行了修订，现将修订后的办法予以
印发，请各单位遵照执行。
特此通知。
华东师范大学
2025年3月4日
第一章总则
第一条为规范强基计划学生培养与管理，服务国家重大战
略需求，加强基础学科拔尖创新人才选拔培养，根据《教育部关
于在部分高校开展基础学科招生改革试点工作的意见》（教学
〔2020〕1号）和《教育部办公厅关于做好强基计划学生管理和
研究生衔接培养有关工作的通知》（教学厅〔2020〕9号）等相关
文件精神，结合学校实际，制定本办法。
第二条学校统筹全校资源为强基计划学生配备优秀师资任
教或担任导师、开放实验室与科研平台、提供一流学习条件、创
造一流的学术氛围和环境，将强基计划学生作为本科卓越育人的
改革典范。
第三条学校成立拔尖与卓越学生培养工作领导小组，负责
强基计划的顶层设计和方向把控，本科生院为秘书单位。
第二章选拔与录取
第四条强基计划招生办法以当年发布的《华东师范大学强
基计划招生简章》为准。
第五条为达成强基计划培养目标，学校实施阶段性考核和
动态进出机制，未通过考核的学生将退出强基计划，选拔综合
素质优秀、认同强基计划培养理念的学生补入，原则上不遴选
补入本科三年级及以上学生。动态进出过程中，强基计划学生
数量不超过所属年份全校强基计划招生计划总数。阶段性考核
和进出办法由强基计划招生专业所属学院（系）制定，报本科
生院备案后实施，重点考察学生的思想品德、专业基础、综合
素质和创新潜力。
第六条学校对入选强基计划的学生在中国高等教育学生信
息网（以下简称学信网）上进行身份标注。
第三章培养与管理
第七条学校本科生院和学生工作部牵头开展强基计划学
生培养成效研讨与评估，组织各培养单位做好学生成长的过程
性管理。
第八条强基计划学生入校后一般不得调整专业，确有特殊
困难或者特殊需要，无法继续在强基计划录取专业学习的，可以
申请在强基计划招生专业范围内转到相近专业。
第九条强基计划学生如未能通过考核或自愿申请退出强基
计划，原则上退出至本专业普通班。退出后，学生原则上不得再
申请转专业，也不再具备申请推荐免试直升研究生的资格。
第十条学校对符合培养要求的强基计划学生实行本研衔接
培养，学生可以申请提前修读研究生阶段的课程。学校要求强基
计划学生开展学术训练并提供相应条件支持，学生需提前进入实
验室或课题组。
第十一条强基计划学生完成规定的本科阶段有关课程，达
到转段要求的，可转段进入本校研究生培养阶段，具体转段办法
按照《华东师范大学强基计划学生本研衔接转段工作管理办法》
的相关规定执行。
第四章附则
第十二条未尽事宜按照学校本科生学籍管理规定及其他相
关规则执行。
第十三条如上级出台新的文件规定，以上级文件规定为准。
本办法将依据上级文件精神，适时进行修订、调整。
第十四条本办法自印发之日起施行，由本科生院负责解释。

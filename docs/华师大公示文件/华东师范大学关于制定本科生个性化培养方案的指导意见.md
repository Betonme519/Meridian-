华东师范大学关于制定本科生个性化
培养方案的指导意见
为深入贯彻《关于加强基础学科人才培养的意见》《教育部关
于加快建设高水平本科教育全面提高人才培养能力的意见》《华
东师范大学卓越育人纲要》等文件和学校第十四次党代会精神，
进一步推进“卓越育人工程”，优化个性化培养路径，促进学生的
自由而全面发展，为拔尖创新人才的培养提供有力支撑，制定本
意见。
一、面向对象
有特殊专长、培养需求，学校已有的专业培养方案、培养项目
无法充分满足其个性化的学术兴趣、知识需求或发展目标的学生。
二、制定原则
1．个性化原则：以学生的自由而全面发展为目标，充分考虑
学生的兴趣、能力、特长以及未来发展，为其制定适合的学习路
径和资源。
2．科学性原则：以学生的能力和素质达成为中心，按照学科
内在逻辑定制课程，符合教育规律和人才成长规律。
3．挑战性原则：个性化培养方案要求达到的能力和素养要高
于原培养方案的要求，鼓励修读高阶挑战性荣誉课程、研究生课程。
4．灵活性原则：允许纳入其他专业、院系、高校的高水平课
程，鼓励跨专业跨学科的人才培养。允许以非传统课程学习形式
（如高质量的项目报告、实践成果等）替代部分必修课程的学分
要求。对于达到免听免修要求的课程，可根据学生的实际情况和
学习能力予以调整。
5．自主性与指导性相结合原则：充分发挥教师专业指导作用
的同时，激发学生的学习主动性，鼓励学生根据自身兴趣、学习
能力和特长，深入思考个人发展规划，进而开展课程选择、设定
及学习方式的探索。
三、制定和实施流程
1. 学生向所在院系提出书面申请，院系配备导师组（不少
于3人，如涉及其他学科，则导师组中至少应包含一名来自相
关院系的教学院长或专业点责任教授共同参与），负责评估学生
是否适合制定个性化培养方案。评估通过后，由导师组和学生
共同制定个性化培养方案初稿。具体申请时间以所在院系实施
细则为准。
2. 导师组将个性化培养方案初稿及初审意见提交院系教学
委员会审议，需获得委员会三分之二以上成员认可方能通过，随
后由分管教学副院长审批，签报教务处。
3. 教务处对培养方案进行审核备案，通过后正式实施。
4. 相关院系应对培养方案实施过程进行监督，并定期进行成
效评估。如个性化培养方案实施效果欠佳或出现所选课程取消开
设等特殊情况，经学生申请、导师组同意、院系批准，报教务处
审核后可对方案进行优化。
四、支持保障
1. 学部、院系应充分利用新生入学教育、主题班会等多渠道，
加强对“一生一案”政策的宣传、解读，提高师生对个性化培养
重要性的认识。
2. 完善本科生导师制和班主任制度，明确导师和班主任在个
性化培养中的职责和作用，加强对学生的个性化指导。加强对“一
生一案”实施情况的持续跟踪和全过程管理，及时发现问题并采
取措施解决。
3. 积极探索新兴技术在个性化教育中的应用，如利用人工智
能技术进行智能推荐、大数据分析学生学习行为、虚拟现实技术模
拟实践场景等，为个性化培养提供强有力的技术支持和创新平台。
4. 在奖学金评定、推荐免试研究生等涉及绩点计算的环节
中，院系可采取灵活措施，对所修读的非本专业课程绩点赋予合
理的调整系数。
5. 将“一生一案”实施情况纳入院系本科人才培养绩效考核
体系，对在个性化培养中表现突出的院系及导师进行表彰奖励。
五、附则
1. 各学部、院系参照本意见制定实施细则，教务处审核通过
后备案并实施。
2. 本意见由教务处负责解释。
3. 本意见自印发之日起施行。

# 华东师范大学本科生成绩管理办法

华东师范大学文件
华师本〔2025〕77号
各单位：
为加强教学过程管理，完善学业成绩评价体系，激发学生的
学习积极性，制定《华东师范大学本科生成绩管理办法》。现予印
发，请遵照执行。
特此通知。
华东师范大学
2025年5月7日
第一章总则
第一条为深入推进以“学生自由而全面发展”为目标、以
“思维能力提升”为牵引的卓越育人模式，激发学生的学习积极
性，加强教学过程管理，完善学业成绩评价体系，根据《华东师
范大学全日制本科生学籍管理规定（2025年修订）》，结合实际，
制定本办法。
第二条本办法所指课程指全日制本科生培养方案所规定的
课程和各种教育教学环节。
第三条成绩评价坚持客观、全面、综合原则，采用平均学
分绩点（GPA）作为综合评价学生学业水平的指标。
第四条本科生院和开课单位加强对成绩评价与管理的监督
检查，鼓励以加强能力考核为导向的课程考核和评价方式改革。
尊重维护教师和学生的权利，将学生课程考核结果如实载入学生
成绩单和学籍档案。
第五条任课教师根据课程教学大纲要求，秉持客观公正的
原则考核评价学生课程修读情况，给出课程成绩。
第六条学生选课完成学习要求并参加考核的，有权获得成
绩评价，课程成绩合格者可获得相应学分。学生未选课的，不可
获得课程成绩和学分。
第二章记分方式
第七条成绩包含课程成绩、课程总评、课程绩点和平均学
分绩点。
第八条同一门课程设平行教学班且教学要求一致的，一般
应统一命题阅卷、统一评价标准、统一计算课程成绩、课程总评
和课程绩点。平行班数量较多的，可由开课单位按一定原则分组
计算。
第九条课程成绩一般由平时成绩和期末考核成绩构成。课
程教学大纲必须明确课程成绩的评定方式和依据，平时成绩应综
合考虑出勤、作业、课堂表现等综合情况。包含理论和实验实践
教学的，理论与实验实践教学成绩占比原则上根据学时数折算，
应在课程教学大纲中明确。
第十条课程成绩的记分方式可采用等级制或百分制。等级
制包含三级制和十级制。
（1）三级制为A（优秀）、P（及格）、F（不及格）。等级A
的比例一般不超过40%。
（2）十级制为A、A-、B+、B、B-、C+、C、C-、D（补考
及格）、F（不及格）。等级A的比例一般不超过30%，等级A和A
－的比例合计一般不超过40%。
（3）荣誉课程和面向卓越学院单独开班的课程选用十级制
的，可增设等级A+，可删减C档，等级A档比例由开课单位制
订具体方案，报本科生院审核通过后，在选课系统课程大纲中公
布并实施。
（4）缓考、重修、免修的成绩不计入等级比例。
第十一条开课单位和任课教师应综合考虑课程类别、特点
和内容等，选用合适的成绩记分方式。思维训练类课程、实习实
践类课程、十人以下的教学班应选用等级制。通识教育课程、经
本科生院审定的公共必修课程应采用三级制。
第十二条除已采用三级制记分课程外，在校期间学生可累
计选择不超过8学分课程，以P（及格）/F（不及格）方式记分
且不计绩点。可选课程范围由开课单位确定，本专业学科基础课、
非实践类专业必修课和部分限定课程，一般不选用P/F方式。
在可选课程范围内，每名学生每学期至多选择1门课程，在
课程期末考核之前2周提出申请，申请即通过。
第十三条课程总评采用等级制记载。
（1）课程成绩的记分方式为三级制（含P/F方式）、十级制
的，等级直接记为课程总评。
（2）课程成绩的记分方式为百分制的，由百分制成绩转化为
十级制等级，记为课程总评。课程成绩60分以下的，记为F；课
程成绩60分及以上的，由电脑排序，按名次比例转化为等级。相
同成绩（保留1位小数）取相同等级。按照本办法附录1“课程
总评与百分制的转化关系”转换。
荣誉课程和面向卓越学院单独开班的课程，课程总评比例由
开课单位制订具体方案，报本科生院审核通过后，在选课系统课
程大纲中公布并实施。
第十四条课程绩点按照本办法附录2“课程总评与课程绩
点的对应关系”计算。考核不合格、三级制（含P/F方式）记分
的课程不计绩点。
第十五条补考、缓考、重修、免修的课程成绩如实记载。
课程总评和课程绩点对应记载如下。
（1）补考不计算平时成绩。补考通过的，课程总评为D，课
程绩点为1.0；补考未通过，课程总评为F，课程绩点为0。
（2）缓考计算平时成绩。课程总评和课程绩点对照原教学班
成绩计算，缓考未通过的不予补考。
（3）重修课程标记（C），课程总评和课程绩点对应当次课
程中非重修学生相同（或最接近）课程总评和课程绩点确定。单
独开设的重修班课程，课程总评和课程绩点按照该课程上一次考
核中相同成绩所对应的课程总评和课程绩点确定。
（4）免修课程的课程总评记为该课程最高等级，如计算绩点，
按最高绩点记。
（5）无考核资格、缺考、考核违纪的，课程总评记为F，课
程绩点记为0。
第十六条平均学分绩点和加权平均分是学生学业的综合评
价指标。
平均学分绩点计算办法：学分绩点为课程学分乘以课程所得
绩点。平均学分绩点为学分绩点之和除以总学分数。重修课程绩
点就近计算1次，考核不通过课程不计入。
加权平均分计算办法：仅百分制记分课程计算加权平均分。
加权成绩为课程学分乘以课程所得百分制成绩。加权平均分为加
权成绩之和除以总学分数。重修课程成绩就近计算1次，考核不
通过课程不计入，非百分制课程不计入。
第三章成绩认定
第十七条经认定后的成绩和学分予以记载。
（一）学生获得经认定的学科竞赛奖项或成果，可认定相应
课程学分。
（二）艺术团学生参加学校规定的训练和比赛，最多可抵充
4个通识教育课程模块课程学分。
（三）体育类专业学生参加学校规定的训练和比赛，最多可
获得10个学分，可抵充通识课程学分或专业教育选修学分。
（四）中国人民解放军（含中国人民武装警察部队）退役后，
可免修《军事理论》（含军训）和公共体育课，课程总评记为P。
第十八条已修读的校内外课程、项目的成绩及学分认定，
根据《华东师范大学本科生成绩及学分认定工作细则》办理。
第四章成绩管理
第十九条任课教师负责课程成绩评定和录入，应于课程考
核结束后的5个工作日内完成课程成绩评定和录入，补考（含缓
考）结束后的3个工作日内完成成绩评定和录入。开课单位负责
课程考核成绩审核及发布。
免修课程成绩由开课单位申报录入，本科生院审核发布。
第二十条学生可通过本科教务系统查询本人课程成绩。学
生对课程成绩有异议的，可向开课单位申请复查。由开课单位组
织相关教师对异议事项进行核查，给出明确答复。复查申请应当
在春季、秋季学期前4周内提出，复查仅限1次。
确系有误的，由任课教师提交更正申请，经开课单位分管教
学领导审核后，报本科生院复核更正。非本校开设的课程，由开
课机构出具说明，由本科生院负责更正。
第二十一条开课单位负责管理课程试卷、答卷和原始成绩
单等成绩档案材料，保存期限不低于四年。除核查课程成绩或教
学检查等工作需要外，任何人不得随意查阅试卷、答卷和原始成
绩单等成绩档案。擅自更改课程成绩，属于严重违纪行为，按学
校有关规定处理。
第二十二条毕业生成绩单由学校档案馆存档。毕业生需要
办理成绩证明的，由学校档案馆出具。
第五章附则
第二十三条各开课单位可根据本办法，结合专业特点制定
工作细则，报本科生院审核备案。
第二十四条本办法由本科生院负责解释。
第二十五条本办法自2025年9月1日起施行，适用于全日
制本科生。原《华东师范大学本科生课程考核与成绩评定管理办
法》（华师教〔2017〕140号）同时废止。

# 华东师范大学本科生休学与复学工作细则

华师本〔2025〕75号
各单位：
为完善完全学分制建设，实行灵活的学习制度，规范本科生
休学与复学，制定《华东师范大学本科生休学与复学工作细则》。

华东师范大学
2025年5月7日
第一条为完善完全学分制建设，实行灵活的学习制度，规
范本科生休学与复学工作，根据《华东师范大学本科生学籍管理
规定（2025年修订）》等有关规定，结合实际，制定本细则。
第二条学生可以在学校规定最长学习年限内分阶段完成学
业。学生申请休学或者学校认为应当休学的，经批准后可以休学。
第三条休学时间以1学期为最小单位，休学时长累计不得
超过2年，起迄时间以本科生院核定为准。
第四条学生有下列情况之一者，应办理休学：
（一）停课治疗、休养时间超过一学期三分之一的；
（二）请假时间超过一学期三分之一的；
（三）因其他原因无法在校学习的；
（四）学校认为应当休学的。
第五条学生申请休学应提交申请，并提供证明材料，经所
在学部院系审核后报本科生院审批备案。
（一）因病申请休学的，须提供二级甲等以上医院提供的证
明；
（二）因私出国出境学习、实习申请休学的，须提供录取通
知；
（三）其他原因申请休学的，须提供事由材料，可视情况要
求补充成年家属知情同意的意见。
第六条学校认为应当休学但学生本人未申请休学的，学校
可要求并通知学生休学离校。休学自通知落款之日起算。
第七条学生应征参加中国人民解放军（含中国人民武装警
察部队），予以保留入学资格或保留学籍。保留学籍可至退役后2
年，保留学籍时长不计入学习年限。
学生参加学校认定的跨校联合培养项目，予以保留学籍。保
留学籍时长计入最长学习年限。
第八条保留学籍按照下列程序办理：
（一）学生应征参加中国人民解放军（含中国人民武装警察
部队），由武装部报本科生院备案。
（二）参加学校认定的跨校联合培养项目，在联合培养学校
学习期间，由本科生院为其保留学籍。
第九条休学学生最迟应在休学起算的1周内办理手续并离
校。
第十条休学期间，保留学生学籍，不予注册，不享受在校
学习学生待遇。因病休学学生的医药费按国家及当地的有关规定
处理。
第十一条学生最迟应在休学（含保留学籍）期满前1周提
交复学申请，经所在学部院系审核后报本科生院备案，经复查合
格方可复学注册。
（一）因病休学的，须提供二级甲等以上医院诊断证明，复
查合格者方可复学。复查不合格者，应继续休学或退学。
（二）退伍学生复学同时报武装部审核备案。
（三）留学生复学同时报国际教育中心审核备案。
第十二条因创业休学的学生符合以下条件者，经审核通过，
休学年限不计入最长学习年限，但累计不得超过2年。
（一）主持项目获得“上海市大学生创业基金资助”或者“获
得风险投资超过50万元人民币（或等值外币）”；
（二）以股东身份深入参与企业运营，且企业规模不低于300
万、所持股份超过20%，可技术入股；
（三）能提供与上述条件同等效力证明材料的。
第十三条留学生服兵役，经国际教育中心审核通过，休学
年限不计入最长学习年限，累计不得超过2年。
第十四条休学期满，逾期未办理复学的，根据学生学业完
成情况，按毕业、结业或退学处理。
第十五条本细则由本科生院负责解释。
第十六条本细则自2025年9月1日起施行，适用于全日制
本科学生。原《华东师范大学本科生保留学籍、休学与复学管理
细则》（华师教〔2021〕128号）同时废止。

## 1. 培养方案结构（背景，最高优先级）

### 1-1 · 培养方案 9 部分构成（E1-2）
培养目标 · 毕业要求 · 学制学位 · 学分要求 · 课程结构 · 教学计划 · 实践教学 · 教学方法 · 修读要求。AI 顾问被问"我专业培养方案有什么"时按此 9 类拆解回答。
来源：学习指南 §培养方案

### 1-2 · 4 大课程结构（E1-3）
华师大本科课程分 4 大类：
- **公共必修课**：思政 · 大学英语 · 体育 · 计算机基础 · 军事理论。学分约 40（全校统一，本文 1-3 详）
- **专业课**：专业必修 + 专业选修。各院系培养方案规定，AI 不知细则就引"查院系培养方案"
- **通识教育课程**：跨学科领域选修，校级要求一般 ≥ 10 学分（具体见培养方案）
- **自主发展课程**：第二课堂 / 创新创业 / 学科竞赛 / 实践类（D6 + C6 类，可结构化部分已入 0005）

来源：学习指南 §培养方案构成

### 1-3 · 公共必修学分（E2-3）
公共必修约 40 学分（思政 ~16 / 大英 ~12 / 体育 ~4 / 计算机 ~4 / 军事理论 ~4，专业 / 入学年份微调）。AI 引"约 40 学分"不强求和。具体免修 / 替代见本文 8 章。
来源：学习指南 §公共必修学分构成

### 1-4 · 学制与最长学习年限（背景）
本科基本学制 4 年（建筑学 / 临床医学等部分专业 5 年）；最长学习年限 = 基本学制 + 2 年。休学时间 / 应征参军时间不计入。
来源：手册 §学籍管理 第x条；详见 0005 track_requirement A1-3

## 2. 注册 / 学籍

### 2-1 · 入学复查（A1-4）
新生入学 3 个月内由学校复查录取资格。复查不合格者 → 取消学籍。AI 触发：新生问"复查会查什么 / 多久出结果"，引手册 §学籍管理。
来源：手册 §学籍管理 第4-6条

### 2-2 · 学期注册（A1-5 / D1-2）
每学期开学按时缴费即注册成功。**未缴费 = 未注册**，未注册不能选课 / 不能参加考核。家庭困难学生可申请学费缓缴 / 助学贷款。
来源：手册 §学籍管理 第7条

### 2-3 · 异地实习仍须注册（D1-3）
学生在外实习 / 交换学习期间，每学期开学仍要回校或委托办理注册手续，否则按未注册处理。
来源：手册 §学籍管理 第7条

### 2-4 · 延长修业期注册（D1-5）
4 年制满 4 年未毕业 / 5 年制满 5 年未毕业，可申请延长修业期 ≤ 2 年。延期期间仍按学年注册并缴学分制学费。
来源：手册 §学籍管理 第x条

### 2-5 · 未注册处理（D1-6）
开学后 2 周内未注册 → 视为放弃学籍 → 学校发书面通知 → 仍不办理 → 按自动退学处理。AI 触发：用户问"忘了注册怎么办"，第一时间引这条 + 2 周硬截止。
来源：手册 §学籍管理 第7条

## 3. 选课与免修免听

### 3-1 · 选课前置（A1-6 / B1-2）
**已注册 → 才能选课**。注册顺序：缴费 → 注册 → 选课。中间任一缺位均触发选课系统拒绝。
来源：手册 §选课退课 第x条

### 3-2 · 学期选课量建议（B1-3）
每学期建议选 20-25 学分；上限一般 ≤ 30 学分；下限 ≤ 12 学分需有指导教师签字（防止学业过轻）。具体见各院系培养方案。
来源：手册 §选课退课 第x条

### 3-3 · 期中退课（B1-4）
学期第 5-10 周可申请期中退课，需指导教师同意。已退课 = 不计入成绩单。每学期退课总数 ≤ 2 门。退课后该课程不再计入学分。
来源：手册 §选课退课 第x条

### 3-4 · 免听条件 + 流程（B1-6）
**条件**：(1) 该课程上次修读已及格 / (2) 自学能力强且有正当理由（如转专业学生重修同名课）。**流程**：开课前 2 周内向开课院系申请 → 任课教师审核 → 可不参加听课但需完成作业 + 考核。
来源：手册 §选课退课 第x条

### 3-5 · 免修条件 + 流程（B1-7）
**条件**：(1) 已通过同等水平测试 / (2) 课程内容已在转入前修过且成绩合格 / (3) 其他特殊情形。**流程**：开学 2 周内向开课院系书面申请 → 审核通过 → 免修该课程并按原成绩 / 测试成绩计入。
来源：手册 §选课退课 第x条

### 3-6 · 免听免修不可申请的课程（B1-5）
**不允许**：思政课 / 体育课 / 实验课 / 实践类课程 / 学位论文 / 大学英语（除测评通过外，见 8-1）。**不允许学生类型**：试读期学生、学业预警未解除学生。
来源：手册 §选课退课 第x条

## 4. 转专业

### 4-1 · 适用条件（A1-7）
入学后可申请转专业，**除以下限制外均可申请**：(a) 招生政策明确不得转出（公费师范生、定向培养） · (b) 学籍异常（试读、休学未满期） · (c) 已被其他高校录取或保送。
来源：手册 §转专业 第x条

### 4-2 · 转入计划数下限（C5-4）
各专业每年接收转入学生数 ≥ 该专业当年招生计划的 5%（保底），具体院系自定上限。AI 触发：用户问"转专业名额"，引此保底 + 让用户查目标院系当年公示。
来源：手册 §转专业 第x条

### 4-3 · 学分修读类型最少课程数（C5-5）
申请转入某专业时，**已修该专业培养方案核心课程 ≥ 3 门**且合格，方可申请。具体核心课程列表由接收院系公示。
来源：手册 §转专业 第x条

### 4-4 · 录取流程（C5-6）
申请 → 院系审核（笔试 / 面试，院系自定）→ 拟录取公示 → 教务处审核 → 正式录取。每年集中受理一次（一般春季 / 第二学期）。
来源：手册 §转专业 第x条

### 4-5 · 卓越学院不受计划数限制（C5-7）
卓越学院（强基计划 / 卓越人才培养实验班 / 拔尖班）转专业不受 5% 下限约束，按院系标准录取。
来源：手册 §转专业 第x条

### 4-6 · 公费师范生（C5-8）
公费师范生**原则上不得转专业**；确需转专业的，按教育部相关规定办理（一般限于本师范专业内调整，跨院系转出极特殊）。
来源：手册 §转专业 第x条

### 4-7 · 参军 / 创业休学转专业豁免（C5-9）
参军退伍复学学生 / 创业休学复学学生申请转专业，**不受计划数 5% 下限限制**，按接收院系学业要求审核。
来源：手册 §转专业 第x条

### 4-8 · 双学位退出 ≠ 转专业（C5-10）
退出辅修 / 双学位 ≠ 转专业。AI 触发：用户问"辅修能否转主修"，明确"不可，是两个独立流程"。
来源：手册 §辅修 第x条

### 4-9 · 转入年级 + 学费（C5-11）
转入后年级一般维持原年级（已修学分多则不降年级）；学费按转入专业当年标准重新核算（学分制学费 = 按实修学分缴）。
来源：手册 §转专业 第x条 + §学分制收费

## 5. 学籍变动：休学 / 复学 / 退学 / 试读 / 毕业类

### 5-1 · 应休学 4 种情形（D2-2）
(1) 经医院诊断需停课治疗超过本学期总学时 1/3 · (2) 一学期内请假超过本学期总学时 1/3 · (3) 应征入伍 · (4) 其他特殊情况（出国 / 创业 / 重大家庭事故）经学校批准。AI 触发：用户描述长期病假，引这条。
来源：手册 §休学复学 第x条

### 5-2 · 休学申请材料（D2-3）
材料：申请书 + 院系审核意见 + 医院证明（病休）/ 入伍通知书（参军）/ 营业执照（创业）等。审批层级：院系 → 教务处 → 学校。
来源：手册 §休学复学 第x条

### 5-3 · 应征参军保留学籍（D2-4）
应征入伍学生保留学籍至**退役后 2 年内**；服役期不计入最长学习年限。退伍后凭退伍证 + 部队证明办复学。
来源：手册 §休学复学 + 教育部 §x章

### 5-4 · 创业休学（D2-7）
学生在校期间创业可申请休学 ≤ 2 年；创业期不计入最长学习年限；复学时需提交创业实绩证明。期间可保留学籍但不享受在校生待遇。
来源：手册 §休学复学 第x条

### 5-5 · 休学离校时点（D2-5）
休学申请获批后 1 周内办理离校手续（退住宿、领走个人物品、办理校园卡冻结）。逾期未离校 → 视为放弃休学，按原状态续学。
来源：手册 §休学复学 第x条

### 5-6 · 复学申请时点（D2-6）
**复学申请须在休学期满前 1 个月**向学校提出，过期未申请按 5-7 处理。复学后编入下一年级（与原年级差 1 年），按当时培养方案修读。
来源：手册 §休学复学 第x条

### 5-7 · 逾期未复学（D2-9）
休学期满**未申请复学 / 复学未通过**：(a) 学校发书面通知 → (b) 30 天内仍不办理 → (c) 按自动退学处理，学籍注销。
来源：手册 §休学复学 第x条

### 5-8 · 退学 7 种情形（A1-10）
(1) 已超最长学习年限仍未达毕业要求 · (2) 休学逾期未复学 · (3) 未注册自动退学 · (4) 经诊断不能继续在校学习 · (5) 一学期未请假缺课超总学时 1/3 · (6) 试读期满仍未达要求 · (7) 本人申请退学。
来源：手册 §学籍管理 第x条

### 5-9 · 试读机制（A1-11）
退学边缘学生（首次触发学业预警高线）可申请试读 1 学期 / 1 学年。试读期间不享受奖学金、不得申请转专业 / 辅修。
来源：手册 §学籍管理 第x条

### 5-10 · 试读流程 5 步（B3-5）
(1) 学校认定触发学业预警 → (2) 学生 + 家长签同意书 → (3) 院系拟定试读计划 → (4) 试读期满院系考核 → (5) 通过则恢复正常学籍 / 不通过则按 5-11。
来源：手册 §学业预警 第x条

### 5-11 · 试读结果（B3-6）
通过 → 恢复正常学籍；不通过 → 按二次退学线（5-12）处理。
来源：手册 §学业预警 第x条

### 5-12 · 第二次退学线 3 条件（B3-7）
试读期满**任一条件触发即退学**：(1) 学业预警仍未解除 · (2) 学分修读量低于本年级培养方案 50% · (3) 出现新的违纪记录。
来源：手册 §学业预警 第x条

### 5-13 · 毕业 / 结业 / 肄业三档（A1-12）
- **毕业**：修满培养方案规定全部学分 + 满足毕业其他要求（如英语、体育、思政考核合格）→ 颁毕业证 + 学位证
- **结业**：修读年限届满但缺少部分学分（≤ 8 学分一般可结业）→ 颁结业证，无学位
- **肄业**：修读年限届满且缺学分较多 / 已退学 → 颁肄业证

来源：手册 §毕业资格审核 第x条

### 5-14 · 延期毕业流程（A2-3）
学制内未达毕业要求 → 可申请延长修业期（见 2-4）→ 期内补足学分 → 申请毕业资格审核。延期期间不享受应届毕业生待遇。
来源：手册 §毕业资格审核 第x条

### 5-15 · 结业生返校补修（A2-4）
结业生 2 年内可申请返校补修缺学分 → 通过后换发毕业证 + 学位证（学位证签发日期为换发日，不是原毕业季）。超 2 年 → 永远只能持结业证。
来源：手册 §毕业资格审核 第x条

## 6. 考核 / 补考 / 成绩复查

### 6-1 · 考核资格（A5-2）
**缺课 + 缺交作业累计 > 该课程总学时 1/3** → 取消该课程考核资格 → 成绩记 0 分 / 不及格。未缺到 1/3 但未交规定作业 → 课程任课教师可酌情扣分。
来源：手册 §课程考核 第x条

### 6-2 · 缓考申请（A5-3）
开考前 2 个工作日内可申请缓考。理由：(a) 病假（医院证明）· (b) 公假（公差通知）· (c) 不可抗力。缓考成绩按正考记，可申请补考。
来源：手册 §课程考核 第x条

### 6-3 · 不予补考情形（A5-4）
**不予补考**：(1) 取消考核资格者 · (2) 考核违纪 / 作弊者 · (3) 公共选修 / 通识选修 / 第二课堂等非必修类（重选即可）· (4) 实习 / 实验 / 论文 / 设计类。
来源：手册 §课程考核 第x条

### 6-4 · 补考课程范围（A5-5）
**可补考**：专业必修 + 公共必修课程，且不在 6-3 排除列表。补考成绩按 60 分封顶，不参与 GPA 计算（按记 60 分 / 不及格二选一，看专业）。
来源：手册 §课程考核 第x条

### 6-5 · 补考时间（A5-6）
一般在下学期开学第 1-2 周内安排。学校教务系统会发通知，学生需在通知期内确认补考意愿。逾期不补考 → 视为放弃。
来源：手册 §课程考核 第x条

### 6-6 · 考核违纪（A5-7）
违纪 / 作弊 → 该课程成绩无效（记 0 分）+ 校级处分（警告 / 严重警告 / 记过 / 留校察看 / 开除学籍）。AI 触发：用户提"作弊"关键词，**先重声严肃后果**，再引此条。
来源：手册 §课程考核 第x条 + §学生处分

### 6-7 · 成绩复查（B2-15）
成绩公布后 5 个工作日内可向教务处申请复查。复查范围：登分错误 / 漏判。**不复查**：评分标准异议（属任课教师裁量权）。复查无误 → 维持；有误 → 修正 + 通报院系。
来源：手册 §成绩管理 第x条

### 6-8 · 评分构成（B5-3）
课程总成绩通常 = 平时成绩（含作业 / 出勤 / 课堂表现）+ 期中考核 + 期末考核。具体比例由任课教师在课程大纲中公示。**总评成绩** = 加权和；GPA 计算见 0005 track_requirement B3 段。
来源：手册 §课程考核 第x条 + §成绩管理

## 7. 辅修 / 双学位 / 个性化 / 拔尖

### 7-1 · 学位授予程序（A3-4）
(1) 学生达毕业要求 → (2) 院系学位评定分委员会审核 → (3) 校学位评定委员会审议 → (4) 公示 7 天无异议 → (5) 授予学位 + 颁学位证。
来源：手册 §学士学位授予 第x条

### 7-2 · 辅修学士学位（A3-5）
**条件**：主修专业 GPA ≥ 学校规定（一般 2.5+）+ 修满辅修培养方案学分（一般 25-30 学分）+ 通过辅修毕业论文。**学位证**：单独颁辅修学位证。
来源：手册 §辅修 第x条

### 7-3 · 双学士学位（A3-6）
**条件**：主修毕业资格满足 + 双学位专业要求课程学分（一般 40+ 学分）+ 双学位毕业论文 + GPA 达学校要求。**学位证**：颁双学位证书，主辅二位并列。
来源：手册 §双学位 第x条

### 7-4 · 撤销学位 / 学术不端（A3-7 / A1-13）
已授予学位 / 颁毕业证学生**事后被认定**学术不端（论文抄袭、考试作弊、伪造成绩）→ 学校学位委员会审议 → 撤销学位 / 学历证书 → 公告作废。无追溯期限制。
来源：手册 §学士学位 + §学位委员会

### 7-5 · 个性化选课学分（C4-3）
**拔尖学生**可申请个性化选课学分，一般不低于专业课总学分的 10%。学生自主跨院系选课，由院系导师签字确认。仅卓越学院 / 学校认定的拔尖学生适用。
来源：手册 §个性化培养 第x条

### 7-6 · 卓越学院结构（C8-3）
卓越学院下设：强基计划班 / 拔尖人才培养实验班 / 卓越教师班 / 卓越医学班等。各班培养方案独立，学分要求一般高于普通班 10-20%。
来源：手册 §卓越学院 第x条

### 7-7 · 卓越学院加入方式（C8-4）
(1) 高考直招（强基计划专项录取）/ (2) 入校选拔（一般大一末或大二初，笔试 + 面试）/ (3) 转入（限大二，按 4-5）。
来源：手册 §卓越学院 第x条

### 7-8 · 拔尖学生特殊待遇（C8-5）

来源：手册 §拔尖人才培养 第x条

### 7-9 · 双学士项目推免（C9-7）
双学士项目学生符合推免条件时，按**主修专业**计入推免名额（不独立占双学位推免名额）。具体见保研政策当年公示。
来源：手册 §推免 + §双学位

## 8. 创新训练 CTP（D6 系列）

### 8-1 · 项目分类 + 申报条件（D6-2 / D6-3）
分 3 类：国家级 / 上海市级 / 校级。**申报条件**：(a) 团队 ≤ 5 人 / (b) 必须有导师签字 / (c) 不与已结题项目重复。
来源：手册 §创新训练 第x条

### 8-2 · 研究时长 + 结项率（D6-4 / D6-5）
研究时长 1-2 年。结项率约束：连续 2 期未结项的学院减少下一期项目名额。
来源：手册 §创新训练 第x条

### 8-3 · 答辩 + 优秀率 + 延期 + 经费 + 冷冻期（D6-6 至 D6-9）
- 答辩通过率约 80%；优秀率限 ≤ 20%
- 延期：1 次延期 ≤ 半年，需导师 + 教务签字
- 经费上限：国家级 ~1 万 / 市级 ~5000 / 校级 ~3000
- 项目放弃：**冷冻期 1 学期**内不得重新申报
- 结题后学分计入 C6-5（已落 0005 track_requirement）

来源：手册 §创新训练 第x条

## 9. 公共课特殊流程

### 9-1 · 大学英语分级（E2-2）
入学后参加分级测试 → 按成绩分 A / B / C 三档 → 不同档次选不同等级的大学英语课。分级测试不及格 → 强制修预备级。具体分级细则各年度有调整，查教务处当年公示。
来源：学习指南 §大学英语

### 9-2 · 计算机课程免修测评（E2-3）
入学后可参加计算机基础免修测评 → 通过则免修计算机基础课程（约 4 学分）→ 替换为其他通识 / 自主发展学分（具体替换规则见院系细则）。
来源：学习指南 §计算机基础

### 9-3 · 师范生实习流程（E4-7）
公费师范生 / 师范专业学生在大三 / 大四参加教育实习（一般 1 学期）。流程：(a) 院系选派实习学校 → (b) 实习前培训 → (c) 实习期间双导师（校内 + 校外）→ (d) 实习报告 + 答辩 → (e) 计入实践学分。
来源：学习指南 §师范生培养 + §教育实习
